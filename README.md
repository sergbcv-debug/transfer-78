# Трансфер 78 — демо-лендинг такси и трансфера

Портфолио-работа под отдельную услугу: сайт для трансфера/такси с расчётом
стоимости поездки. Компания вымышлена, в подвале это написано.

## Файлы

```
index.html      страница: первый экран с калькулятором, цифры, преимущества,
                тарифы, шаги, FAQ, форма, подвал
styles.css      база кита (светлая структура)
themes/dark-yellow.css  тема: графит #0b0b0c + жёлтый #ffd400
transfer.css    раскладка первого экрана, калькулятор, FAQ
calc.js         расчёт: посадка 200 ₽ + км × ставка + доп. услуги
form.js         отправка заявки (имя, телефон, маршрут, комментарий)
server.py       приём заявок → zayavki.jsonl
tools/check.py  проверка разметки, контраста и веса
```

## Запуск

```powershell
cd C:\Projects\sites\transfer
python server.py --port 8099     # http://127.0.0.1:8099
```

## Калькулятор

Ставки: эконом 35 ₽/км, комфорт 45, бизнес 70, минивэн 55; посадка 200 ₽;
детское кресло +300 ₽, встреча с табличкой +500 ₽.

Итог = 200 + км × ставка + опции. Кнопка «Заказать по этой цене» подставляет
расчёт в комментарий формы — заявка приходит с готовой суммой.

Проверено: при 25 км и экономе выходит 1 075 ₽, текст расчёта
«посадка 200 ₽ + 25 км × 35 ₽. Итог фиксируем при подтверждении» подставляется
скриптом (видно в DOM).

## Почему жёлтый

Жёлтый с графитом — принятый цвет такси и трансфера, его понимают без объяснений.
Для автосервиса та же тема не годится: там уместнее светлая или «цеховая».
Тема лежит отдельным файлом и переключается одной строкой.

## Что заменить под клиента

1. Название, телефон, город и зону работы (шапка, первый экран, контакты).
2. Ставки в `calc.js` и в таблице тарифов — они должны совпадать.
3. Аэропорты, вокзалы и города в тексте первого экрана.
4. Вопросы в FAQ — реальные, из разговоров с клиентом.
5. Контакты для заявок: сейчас пишутся в файл, для хостинга — Telegram или почта.
